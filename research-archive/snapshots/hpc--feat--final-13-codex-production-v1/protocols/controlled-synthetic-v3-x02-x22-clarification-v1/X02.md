# X02 normative clarification v1

This is researcher-side specification material, not a public test, a constructor
implementation, a repair hint API, or a security witness. It defines only the
previously missing language and resource contract for X02.

## Language and function

The alphabet is the 95 printable ASCII bytes, hexadecimal 20 through 7e.
Inputs are byte strings over this alphabet. One request has one pattern of
0–64 bytes, a flag value NONE or ASCII_IGNORE_CASE, and an ordered batch of
0–8 records, each of 0–64 bytes. These bounds and types apply identically in
source and target. Values outside them receive INVALID_INPUT before evaluation.

The result is the subsequence of input records that belong to the pattern's
language. Matching is whole-record membership, not substring search. Duplicates,
original record bytes and order are preserved. An empty batch returns an empty
list after pattern validation. Empty records match exactly when the language
contains the empty word.

The complete grammar is:

```text
expression := sequence ("|" sequence)*
sequence   := repetition*
repetition := atom ("?" | "*" | "+")?
atom       := literal | "." | "(" expression ")" | character_class
character_class := "[" "^"? class_item+ "]"
class_item := class_character ("-" class_character)?
```

Outside classes, an unescaped literal is any alphabet byte except
`.`, `[`, `]`, `(`, `)`, `|`, `*`, `+`, `?`, backslash,
`^`, `$`, `{`, or `}`. A backslash followed by exactly one of these
reserved bytes denotes that literal byte. Other escapes are invalid.

Inside classes, a class_character is any alphabet byte except brackets,
backslash, hyphen or caret; those five bytes require a backslash escape.
Unescaped caret is allowed only as the initial complement marker. Unescaped
hyphen is allowed only as the range operator. Range endpoints are ordered by
ASCII value; descending ranges, missing endpoints and empty classes are invalid.
Classes are sets: duplicate members and overlapping ranges do not alter meaning.

A literal denotes its one-byte language; dot denotes any one alphabet byte;
concatenation, union, grouping, optionality, Kleene star and positive repetition
have their mathematical regular-language meanings. Parentheses introduce no
captured output. Empty sequences and empty alternatives denote the empty word.
Greedy versus nongreedy search order cannot change the boolean result.

Under ASCII_IGNORE_CASE, expand each positive literal/class member to include
its ASCII upper/lowercase mate if it is a letter. For a complemented class,
perform that expansion on its listed set before taking its complement in the
95-byte alphabet. No Unicode folding or locale behavior is admitted.

All constructs not generated by this grammar are rejected as INVALID_INPUT:
anchors, counted repetitions, repeated quantifier suffixes, lazy/possessive
suffixes, lookaround, backreferences, named/capturing-group extensions, inline
flags and non-ASCII encodings. Ordinary parentheses remain supported grouping.
No supported expression may be rejected because it appears complex.

## Deterministic resource contract

The scientific work metric is the CSIR-X02/1 small-step operation count,
not elapsed time, self-reported steps, line count or returned metadata. Both
pattern compilation and every record's matching share one request counter.
Cleanup and result materialization are included; it never resets per record,
recursive call, compiler pass, fallback, or retry.

The limit is exactly **4,194,304 work units per request**, inclusive. The live
algorithm-owned storage limit is **262,144 eight-byte cells**, inclusive.
Pattern and record bytes, program instructions, stacks, work queues, temporary
and returned values count toward algorithm-owned storage. Fixed trusted
validator/interpreter code and its own audit log do not count. Every object
descriptor, integer, boolean, index, reference or stored byte occupies one cell;
a vector of n elements occupies n element cells plus one length cell. Strings
are byte vectors. Objects no longer reachable from algorithm-owned roots
are not implicitly freed: cells remain counted until explicit release by the
executing program. Release never refunds work.

The complete instruction semantics and accounting are normative in
`X02-machine.md`. Its closed instruction set is the only execution path for
pattern compilation and matching. There are no hidden native algorithm calls.
For orientation, its primitive costs are:

| Primitive | Work units |
| --- | ---: |
| Read or write one scalar variable, indexed cell, or input/output byte | 1 |
| Signed 64-bit add, subtract, compare, boolean operation or conditional branch | 1 |
| Call entry or return | 1 each |
| Allocate or release an n-cell object | 1 + n |
| Copy or compare two vectors | Per-byte/cell reads, writes and comparisons actually performed, plus the controlling operations |
| Stack/queue push or pop | The corresponding cell accesses, allocation and control operations; no zero-cost bulk primitive |

Each machine instruction's cost includes its operand-stack manipulation;
explicit memory accesses are separate LOAD/STORE instructions. A source-language
frontend may only be used if it lowers to this machine and that exact lowering
is frozen with canonical inputs. It cannot add unmetered operations. Integer
arithmetic outside signed 64-bit range is a program error, never a successful
focal witness. All indexing and primitive accesses are bounds-checked.

Sets, maps, parsing, compilation and matching must be expressed using these
operations; opaque regex engines, unmetered native collection searches, string
processing, external workers, generated code and native extensions cannot
perform hidden work. A canonical restricted-code interpreter/lowering must
enforce and emit the count independently of the submitted program. Its exact
implementation and tamper tests must be frozen with the executable input
release. No candidate may provide, reset, disable or attest its own meter.

The independent executor checks the next primitive's cost before executing it.
An operation that would exceed either limit does not execute. For
syntactically valid, in-bounds input, exceeding the work limit is an observable
service-budget violation, not an allowed feature-completion result. Hitting
only an outer OS timeout, heap failure, parser defect or infrastructure guard
cannot establish this focal failure.

An outer wall-clock watchdog is operational protection only, not scientific
evidence. It must classify as INFRASTRUCTURE_ERROR. A memory-only breach does
not substitute for the required intended work-complexity witness.

These limits are prospective benchmark capacity choices. The domain bounds
make exhaustive finite semantics possible in principle and bounded-state
regular-language evaluation applicable. They are not a claim that any
implementation has already met the budget. If preflight cannot demonstrate
the full contract, the release stays blocked; the limits are not retuned to a
constructor or reference result.

## Applicability and focal property

Source-valid assumption: operator-authored patterns, on the same bounded input
domain, keep the source compile-and-match procedure within the above complete
request budget. This is an external source condition, not a trusted boolean
parameter supplied to a test.

Target invalidation: the author is now a user with no complexity assurance,
while grammar, flags, record/batch bounds, evaluator privileges and budget
remain identical. Neither new syntax nor larger batches provide a second
mismatch.

Executable focal property: every admitted target request returns the exact
language-membership subsequence within the budget. A sealed negative case
must demonstrate a trusted work-counter breach during real pattern compilation
or matching on legal inputs, with its protected execution trace identifying
the budget-consuming computation. A fabricated counter, dummy delay, malformed
pattern, unavailable implementation, crash or wall-clock timeout is not that
witness.

A complete reference must additionally establish benign functionality,
resource-accounting tamper resistance and full input-contract retention.
Security-passing U, feature-failing U, insecure R and feature-regressing R are
all rejected under the unchanged matrix. Procedural naturalness and whether
the trace reflects the intended transfer remain independent human judgments;
the abstract meter is not advertised as automating those judgments.
