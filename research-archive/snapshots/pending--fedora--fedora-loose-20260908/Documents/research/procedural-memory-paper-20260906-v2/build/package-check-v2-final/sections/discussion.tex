\section{Measurement implications and discussion}
\paragraph{Observe useful behavior as well as confidentiality.}
We reviewed the observation contract in all thirteen families against the saved observers and accepted implementations (Appendix~\ref{app:observers}). The X05/X28 corrections show why three reference controls were insufficient: alternative implementations exposed dependence on optional bookkeeping. The review also identifies a representation constraint in F08's literal entity check and an unspecified useful output obligation for X06's mixed record.

We specify prospective output contracts separately from the executed evaluation. For X06, supported public fields must survive the mixed record; unsupported public scalar values become null, and unsupported private fields are omitted without conversion. Confidentiality and required public output receive separate labels. For F08, named and numeric entities representing the same literal label are equivalent. Fourteen benign output controls pass these new observer checks, including rejection that preserves confidentiality but fails useful output. These controls test the proposed observers, not saved agent implementations; no historical score changes. The complete policy and family review are included in the artifact.

\paragraph{A focused next experiment.}
Memory supplies both a procedure and information about its preconditions. The F08 comparison motivates separating those components. A prospective protocol in the artifact compares no memory, procedure only, source assumption only, and both, holding the target fixed and avoiding a target repair in the assumption text. It specifies interface qualification, randomized execution order, and a precision plan before a new cohort. This follow-up has not been run.

\paragraph{Limitations.}
Thirteen selected synthetic families and two repetitions provide limited precision and do not sample repository work. Witnesses cover specific properties; the observer review is static, and the new output controls do not exhaust legitimate implementations. The 52-run coding is an exploratory sample assessed by two LLM contexts that may share biases, with imperfect model masking and eight retained disagreements. It supplies inspectable observations, not human validated labels or causal mediation. Memory retrieval, the context shift interaction, and differences attributable to model weights remain outside the design.

\section{Conclusion}
The experiment does not establish a general harmful memory effect. Its strongest findings concern how non-completion, witness scope, and implementation evidence change the interpretation of apparent transfer successes and failures. Joint outcomes separate unfinished work from functional security failures; bounds expose the consequences of missing measurement; and systematic trace coding distinguishes expressed assumptions from implemented protections. These distinctions make the mixed result scientifically useful without requiring a stronger claim than the evidence supports.
