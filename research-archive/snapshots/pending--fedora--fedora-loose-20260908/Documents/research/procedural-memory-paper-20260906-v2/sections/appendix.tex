The final construction manifest binds six retained F families and seven admitted X families to immutable specifications and candidate artifacts. \section{Analysis specification and sensitivity}
\label{app:sensitivity}
For configuration $m$, contrast $a-b$, and outcome $Y\in\{F,S,U\}$, let $\mathcal{E}_{m,a,b}$ contain families for which both repetitions in both conditions are technically valid and have observed F and S. The estimate is
\begin{equation}
\widehat{\Delta}_{m,a-b}^{Y}=\frac{1}{|\mathcal{E}_{m,a,b}|}\sum_{f\in\mathcal{E}_{m,a,b}}\left[\frac{Y_{m,f,a,1}+Y_{m,f,a,2}}{2}-\frac{Y_{m,f,b,1}+Y_{m,f,b,2}}{2}\right].
\end{equation}
We multiply by 100 to report percentage points. Eligible sets are contrast-specific. The correction changes no eligibility decisions. There is no pooled model ranking or substitution of an invalid repetition by an offline result.

\paragraph{Uncertainty.}
The displayed intervals resample the eligible paired family differences with replacement 20,000 times and take the 2.5th and 97.5th percentiles. The reproducible generator uses a fixed analysis seed and retains the two repetitions inside each family unit. These intervals are exploratory and condition on the observed family set; they do not account for uncertainty in task construction, eligibility dependent on outcomes, scoring scope, or all possible repeated agent generations. Zero observed variation produces a degenerate bootstrap distribution, not a precise population guarantee.

The two-sided family sign-flip diagnostic enumerates sign assignments to the family differences and requires a symmetry/exchangeability assumption. It is not a randomization test justified by randomized signs in this design. Leave-one-family-out ranges describe the influence of individual observed families. Scope omissions and these diagnostics were chosen during review and are not replacement primary analyses.

\section{Observer review and prospective output contracts}
\label{app:observers}
We statically inspected the saved focal observers and family contracts for all thirteen families and inventoried saved functionality and focal witness passes. Distinct parsed syntax trees describe accepted implementation diversity; they do not establish that the implementations are independently legitimate or semantically distinct. The family table records the observable effect, remaining contract issue, and this acceptance inventory. No saved implementation was executed for this review.

\paragraph{Prospective X06 contract.}
Version 2 separates confidentiality C2 from required public output R2. A supported dictionary root retains the public correlation, message, and code fields. Supported JSON scalars survive; unsupported or nonfinite public scalar values become null. Unknown private fields are dropped without conversion. Child order is retained with depth and length limits, and unsupported children become empty objects. Error objects expose only type and code with the same scalar policy. A mixed record with an unsupported private value must still emit its public projection. An invalid root, exceeded limit, or sink failure returns a logging error without output. The artifact specifies exact field, depth, and length rules. Decoded JSON comparison permits key order, whitespace, and equivalent escaping, while rejecting duplicate keys. Historical rejection is not retroactively declared incorrect.

\paragraph{Benign observer controls.}
The new X06 observer checks separate confidentiality and useful output on compact, reordered, and escaped equivalent outputs, rejection, missing public information, an extra restricted marker, duplicate keys, representation calls, and unsupported public values. The new F08 observer accepts named or numeric entities that represent the same harmless literal label inside one span and rejects lost text or added elements. All fourteen manually specified output controls pass. These are acceptance tests for the new observers, not a reevaluation of the historical cohort or independent validation of all thirteen evaluators.

\section{Artifact and reproduction}
The anonymous artifact contains the 624 outcome rows with original and corrected labels; exact configurations, task and memory records; reference control observations; saved implementation and patch text; available visible traces; the measurement sidecar; coding packets and separate labels; observer contract versions and hashes; and analysis code. Stable record identifiers connect saved evidence to outcomes and claims. Source, analysis, and static evidence packages are separated for inspection. Coverage and redaction receipts report unavailable traces and transformations.

The artifact supports independent inspection of saved implementations and visible behavior and recomputation of reported statistics. It includes evaluator version identifiers, observer hashes, reference observations, and the complete saved outputs used by the analysis. The executable witness inputs remain sealed during review, so the release does not independently rerun the security evaluations. Private evidence mappings retain original run IDs, paths, and manifest hashes separately. No credentials, local hostnames, or personal paths are needed for the public analysis.

Use \texttt{make analyze} for tables and figures, \texttt{make measurement-check} for the fourteen benign output controls, and \texttt{make all} for both workshop wrappers. The prospective memory content ablation is a planning artifact, with no new outcomes combined into this cohort.
