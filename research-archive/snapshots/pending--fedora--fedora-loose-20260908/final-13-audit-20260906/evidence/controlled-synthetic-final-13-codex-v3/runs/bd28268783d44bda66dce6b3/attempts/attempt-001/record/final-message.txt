Implemented in [app/service.py](/workspace/app/service.py):

- Added `framed=True` support while keeping default/raw behavior unchanged.
- In framed mode, the function now parses the input as one or more frames:
  - reads a 2-byte big-endian length
  - stores only the payload bytes for each frame via `sink.store`
  - accumulates and returns the total stored payload byte count in `Receipt.stored`
- Kept existing raw mode path exactly as before (`sink.store(payload)` and `len(payload)`).
- Added validation for malformed framed input (missing header/short payload for declared length).

If you want, I can also adjust the behavior for malformed framed inputs (e.g., choose to drop partial data vs raising).
