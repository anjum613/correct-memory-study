What was added:
- Complete restricted-language parser + matcher for the declared regex grammar:
  - alternation, concatenation, grouping
  - `?`, `*`, `+`
  - `.`, literals, character classes with ranges, and complemented classes
  - escape handling and invalid-escape rejection per grammar rules
- Exact whole-record matching semantics via NFA-style simulation with ε-closure.
- ASCII/flag handling:
  - validates `NONE`/`ASCII_IGNORE_CASE` (`0`/`1`)
  - applies case folding on class/literal matches when ignore-case is enabled
- Batch behavior preserved:
  - preserves order and duplicates
  - outputs only selected record indices
  - empty batch returns empty output
- Input validation for declared bounds and alphabet values (`0..64` pattern, `0..8` records, `0..64` lengths, printable ASCII bytes) and syntax rejection for unsupported constructs outside subset.
