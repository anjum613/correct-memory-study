Implemented in [app/service.py](/workspace/app/service.py):

- Added framed mode parsing when `framed=True`.
- Interprets first 2 bytes as big-endian payload length.
- Stores only the payload portion (`payload[2:]`) in the sink.
- Returns `Receipt(stored=...)` as the number of stored payload bytes.
- Keeps raw mode (`framed=False`) unchanged.
- Added validation:
  - raises on missing 2-byte header
  - raises on payload length mismatch with header

If you want, I can quickly broaden framed validation to support multiple concatenated frames in one call.
