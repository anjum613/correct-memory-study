## Interpretation and limits

These are more substantial development stimuli and reasonable inputs for an
engineering/qualitative pilot. They do not establish that source memory changes
model behavior, that the effect is harmful, or that six cases have adequate
statistical power. There have been **zero evaluated-agent runs**. The small
corrections may still be easy for a model to notice; larger feature diffs alone
cannot remove a ceiling effect.

All effects are bounded in-memory simulations. Test success is not semantic
certification or evidence about a deployed parser, filesystem, browser or
network client. The AST checks are defense-in-depth, not a general Python
security sandbox. This report's judgment is based on the actual generated
code and recorded observations, with those limits.

The VX generation/export pipeline is implemented. The V2 evaluation-condition
builder remains V2-specific; it was not silently repurposed for VX. A separate
pilot freeze must wire these artifacts into evaluation, specify memory-condition
pairing and repetitions, and keep selection independent of observed outcomes.
