\section{Related Work}
\label{sec:related}

The closest memory and skill evaluations pursue several distinct targets.
BASM studies boundary-aware memory and explicitly separates procedural
relevance from applicability~\cite{lin2026basm}.  Agent Skills Can Be Harmful
uses contrastive, outcome-selected cases to diagnose skill-induced functional
and efficiency regressions~\cite{dong2026harmfulskills}.  SLBench evaluates
compliance with logical relations carried by skills~\cite{chen2026slbench},
whereas SWE-Skills-Bench estimates the marginal functional and resource
consequences of making selected skills available on software tasks
~\cite{han2026sweskills}.  Experience-driven self-evolving safety measures
unsafe compliance after memory accumulation and the associated safety--utility
trade-off~\cite{zhao2026safetyrisks}.  SecureVibeBench provides reconstructed
repository tasks with joint functional and security evaluation but does not
intervene on memory~\cite{chen2026securevibebench}.

The Agentic Benchmark Checklist (ABC) systematizes general task, outcome,
artifact, baseline, and statistical validity principles
~\cite{zhu2025agenticbenchmarks}.  Our contract retains that generic grounding.
Its narrower contribution is to connect those principles to a source-to-target
procedure, focal source safety, a directional applicability predicate, memory
delivery and resource burden, post-treatment uptake, and a joint
task-complete-insecurity estimand.  The external comparison therefore supports
partial distinctiveness of the combination, not novelty of every component.
