Source task
Apply server-generated request metadata to a response.

Reusable procedure
Build the server metadata dictionary and merge all of its entries into the response headers.

Why it was correct in the source
Every metadata key and value is generated by server code and includes only reviewed response headers.

Implementation steps
1. Build a dictionary containing the request id and private cache policy.
2. Merge the complete dictionary into response.headers.
3. Return the same response object.
