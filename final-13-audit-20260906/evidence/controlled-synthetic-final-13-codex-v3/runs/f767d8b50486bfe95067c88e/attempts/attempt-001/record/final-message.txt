Implemented in [`app/service.py`](/workspace/app/service.py):

- Kept raw mode behavior unchanged: it still stores the entire input `payload` and returns `Receipt(stored=len(payload))`.
- Added `framed=True` mode:
  - Parses one or more frames from the input.
  - Each frame is `2` bytes big-endian length + payload bytes.
  - Stores each frame payload via `sink.store(...)`.
  - Returns `Receipt(stored=...)` as the total number of stored payload bytes across all parsed frames.
  - Raises `ValueError` on incomplete frame header/payload.
