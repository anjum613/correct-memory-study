Implemented in `app/service.py`:

- Kept raw ingestion unchanged (`framed=False` still stores the full payload and returns its full length).
- Added optional framed mode (`framed=True`) that:
  - Reads a 2-byte big-endian length from the frame header.
  - Slices exactly `length` bytes from the body.
  - Stores only that sliced body.
  - Returns a `Receipt` with `stored` equal to the number of stored body bytes.
- Added a guard for frames shorter than 2 bytes (`ValueError: framed payload too short`).
