Implemented in [`app/service.csirpy`](/workspace/app/service.csirpy).

`boot()` now:

- Builds a Thompson-style epsilon NFA for the full declared regex subset from the input pattern bytes.
- Supports precedence (`|`, concatenation, `*`, `+`, `?`), grouping, character classes (including complement), class escapes, and empty sequences/alternatives.
- Applies `ASCII_IGNORE_CASE` expansion for literals/classes (including complements by expanding then inverting).
- Evaluates each record in input-order against the compiled automaton and appends matching record indices to the output vector, preserving original ordering and duplicates.
- Preserves empty-match behavior via ε-closure handling.
- Returns a normal result region usable by the host (`[count, selected... ]`).

I did not run tests here. If you want, I can also provide a quick walkthrough of edge-case coverage (especially `EMPTY` pattern, `a|`/`|a`, and complement class behaviors).
