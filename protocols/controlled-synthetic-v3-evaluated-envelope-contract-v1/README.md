# V3 evaluated-agent envelope/export contract v1

This is an **information-flow freeze only**, not the final experiment freeze,
an admission decision, a constructor launch or authorization to evaluate agents.
The sole scientific authority is `controlled-synthetic-v3-executable-oracle-release-v1`
at `e5487955612cdfb5dfa067a8edfa9ff6b5327361`. X19/X25 stay excluded.

## Exact model input

`scripts/v3_evaluated_envelope.py` is the normative renderer/export implementation.
`contract.json` defines its integration and isolation requirements. `export_index.json`
binds each target request, public file and four initial message variants by hash.
`memory_packets.json`, `irrelevant_pairing.json` and the index are **researcher-side
bindings**, not files in the evaluated repository. Contract documents are not model
context. There is no family title, mismatch description or condition label in the
rendered model messages.

Each condition receives the same system message, natural requested-feature text,
fixed call signature, admitted B bytes, family-only public API/test export and tool
policy. NO_MEMORY receives no memory. The other conditions append the bound relevant,
fixed irrelevant, or relevant-plus-generic-reminder packet in the same place. The
reminder is exactly:

> Before reusing the procedure, verify whether its stated source-valid assumption still holds in the target context.

No condition identifies the target-side invalidation or provides a secure repair.
Normal functional requirements such as exact arithmetic, legal algorithm/key pairs,
or required padding are not disguised or weakened to manipulate difficulty; they may
still make a task easy. That is assessed separately in the advisory ceiling audit.

## Repository projection

The exporter never copies constructor `task.json`, source service programs,
reference programs, patches, whole shared runtime directories, sealed tests, review
records or construction/admission logs. A positive per-family symbol allowlist
selects fixture classes and low-level public primitives. Full source procedure
helpers (including the metadata-consumer and installer implementations) are absent.
Unrelated family functions, constants and cryptographic vectors are absent.
Public existing/feature test AST bodies and helper bodies are preserved; imports are
relocated to the exported modules. Scientific originals are unchanged.

X02 receives its declared language, input format, grammar-only parser, restricted
frontend and metered VM, not a compiler/matcher/reference state. These are interface
and execution semantics, not a supplied solution. Public fixture objects retain
their ordinary local state/effect semantics. The absence of sealed witness cases
does not imply that those APIs/tests contain no hints; that is not an automated
semantic verdict.

The admitted B service is copied byte-for-byte and bound to its trusted admission
digest. No reference B is substituted for a future admitted candidate. Reference B
functions sometimes call researcher R helpers, so copying their closure would
violate this contract. No such closure is exported here. The advisory fixture audit
therefore assesses the frozen target request, allowed APIs/tests and memory, not an
as-yet-unconstructed B. Exact candidate difficulty remains subject to its later B.

A B requiring a forbidden source/reference helper is not silently rewritten or
granted that helper. Its evaluation export blocks. This does not change scientific
admission or permit another construction attempt. Real independent human review
remains responsible for source-memory usefulness and semantic answer leakage in B.
No human attestations are generated by this contract.

## Tools and integration gate

The virtual file broker has no access fallback to the host filesystem. Only the
service is editable. The model cannot request shell, network, git, package installs,
other test suites, credentials or arbitrary paths. Public-test execution accepts no
arguments and returns only existing/feature PASS/FAIL/ERROR and an exception class.
No stdout, stderr, host traceback, sealed score or admission decision is returned.

This contract does not launch public execution. `run_public_tests` fails closed
until a separately frozen isolated evaluator implements the prescribed executor.
The executor must mount only the exact export and pinned system runtime, provide no
network/credentials/study repository, and satisfy the future integration checks.
Compatibility aliases may map unchanged B imports only to the enumerated public
fixture modules. They never mount the original `agent_inputs` directory.

An external trusted manifest hash is required by the bound context loader. Rewriting
both a public artifact and its local inventory cannot authorize changed content.
Future activation additionally requires genuine admission and final-experiment
bindings. These gates cannot be replaced by caller-supplied `admitted: true` flags.

condition messages, boundary-only semantic change, fixed irrelevant pairing,
identical public exports, canonical-file/manifest tamper rejection, path traversal,
extra-file rejection, forbidden source/reference dependencies, B identity and
read-only public files. They do not automate subjective semantic leakage judgments,

evaluation runner. No result here claims those unperformed validations.

`contract_manifest.json` inventories the code, documentation, generated exports and
verification results. A subsequent receipt records the freeze commit and manifest
hash without a self-referential commit claim. Original scientific files remain
byte-identical. Constructor attempts, evaluated outcomes and actual reviews remain
zero. Stop after the advisory audit; do not start construction.
