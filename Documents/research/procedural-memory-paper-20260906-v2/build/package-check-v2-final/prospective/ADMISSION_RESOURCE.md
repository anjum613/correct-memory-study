# Earlier admission rule as a construction resource

This note extracts the reusable design principle from the earlier frozen Track B six-family expansion rule. It is separate from the final synthetic cohort and does not claim repository task admission or evaluated agent outcomes.

The earlier rule preserves the original deterministic candidate rank, resolves higher-ranked candidates before admitting lower-ranked candidates, and records every rejection with its reason. Prior model outcomes are prohibited selection inputs. Source correctness, memory fidelity, a functional unadapted target that fails the focal witness, and a functional repaired target that passes it are separate requirements. Source and target state propositions must be supported by compatible historical states before a family is admitted.

The associated control-only nonvacuity demonstration includes an acceptable construction, an already solved baseline that is rejected, and an invalid donor that is rejected. The later ten-attempt repository feasibility ledger has no admitted task and two technically unevaluable cases. These records support a reusable admission discipline and a bounded feasibility result; they do not support a successful repository benchmark.

Track A is named as a separate unopened route in the expansion rule. Its relationship to the complete candidate collection and the final synthetic families is not established by the retrieved final artifacts. No collected-candidate-to-thirteen selection pipeline is asserted.

The anonymous release contains this methodological summary only. The private asset assessment records exact source paths, versions, hashes, counts and provenance. Repository candidate code and its redistribution rights are outside this release.
