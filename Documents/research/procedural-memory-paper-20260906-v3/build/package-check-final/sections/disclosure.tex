\section*{Declaration of LLM Usage}
Within experimental artifact construction, LLM assistance was limited to proposing synthetic family components. Admission criteria, target contracts, reference roles, and focal witnesses were frozen separately under the saved construction protocol. The coding agents evaluated in the experiment are themselves LLM based. Two isolated LLM sessions, recorded as \texttt{gpt-6-astra} with \texttt{xhigh} reasoning in Codex CLI 0.153.4, produced the exploratory codes for the 52-run behavioral sample; no backend revision was exposed. LLM assistance was also used for evidence organization, analysis code preparation, and manuscript preparation. The authors remain responsible for the study design, reported claims, and final text. No new evaluated agent runs or saved candidate executions were performed during manuscript preparation.
